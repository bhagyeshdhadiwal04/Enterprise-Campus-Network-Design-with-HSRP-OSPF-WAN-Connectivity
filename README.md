# Enterprise-Campus-Network-Design-with-HSRP-OSPF-WAN-Connectivity
Designed a two-building enterprise network using Cisco Packet Tracer. Implemented six VLANs, 802.1Q trunking, SVI-based inter-VLAN routing, HSRP gateway redundancy, Layer 3 switching, OSPF dynamic routing, and WAN connectivity. Performed end-to-end connectivity testing to verify network communication and redundancy.
